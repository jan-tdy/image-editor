# Keyboard shortcuts

## Main window

| Action | Shortcut |
|---|---|
| Open file / folder | ++ctrl+o++ / ++ctrl+shift+o++ |
| Save / Save As | ++ctrl+s++ / ++ctrl+shift+s++ |
| Undo / Redo | ++ctrl+z++ / ++ctrl+shift+z++ |
| Rotate left / right | ++ctrl+l++ / ++ctrl+r++ |
| Flip horizontal / vertical | ++h++ / ++v++ |
| Crop | ++c++ (++enter++ apply, ++esc++ cancel) |
| Adjustments panel | ++ctrl+u++ |
| Zoom in / out | ++ctrl+plus++ / ++ctrl+minus++ |
| Fit to window / 100 % | ++ctrl+0++ / ++ctrl+1++ |
| Next / previous | ++right++ / ++left++ |
| Delete file | ++del++ |
| Rename file | ++f2++ |
| Fullscreen | ++f11++ |
| Slideshow | ++f5++ |

## Tools

| Action | Shortcut |
|---|---|
| Batch Rename & Edit | ++ctrl+b++ |
| Join Images | ++ctrl+j++ |
| Auto-Stack | ++ctrl+shift+j++ |
| Photo Triage | ++ctrl+shift+k++ |

## Photo Triage window

| Action | Shortcut |
|---|---|
| Keep | ++k++ |
| Favourite | ++f++ |
| Trash | ++t++ / ++del++ |
| Next (decide later) | ++right++ |
| Back | ++left++ / ++backspace++ |

Letter keys are ignored while the name field has focus.
